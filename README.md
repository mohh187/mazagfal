# Mazag Fal Café Menu

Immersive 3D-inspired Arabic café menu experience with floating drink cards, parallax motion, and responsive layouts.

## View the Menu Locally

1. Install Node.js (v18+ recommended) and run `npm install` once (no dependencies are installed, but it prepares the lock file for consistency).
2. Launch the bundled server with:

```bash
npm start
```

3. Visit [http://localhost:8080](http://localhost:8080) to explore the menu. To change the port, prefix the command with `PORT=9000` (or any available port).
4. Stop the server anytime with `Ctrl+C`.
