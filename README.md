# Mazag Fal Café Menu

Immersive 3D-inspired Arabic café menu experience with floating drink cards, parallax motion, and responsive layouts.

## Development

1. Install Node.js (v18+ recommended).
2. From the project root, install dependencies (none required) and run the static server:

```bash
node server.js
```

The site will be available at [http://localhost:8080](http://localhost:8080) by default. Set the `PORT` environment variable to use a different port.
